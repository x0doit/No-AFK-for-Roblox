# No AFK for Roblox • Errors With Run

Если программа не запускается, откройте страницу [Решение проблем](https://github.com/x0doit/No-AFK-for-Roblox/wiki/Решение-проблем) в wiki. Чаще всего не хватает Microsoft Visual C++ Redistributable (ошибка «MSVCP140.dll не найден»): установите [VC++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe).

If the app does not start, see [Troubleshooting](https://github.com/x0doit/No-AFK-for-Roblox/wiki/Troubleshooting) in the wiki. The usual cause is a missing Microsoft Visual C++ Redistributable ("MSVCP140.dll is missing"): install the [VC++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe).
